# Quickstart Validation: Task Management

## Prerequisites
- Node.js v26.4.0
- npm v12.0.1
- Angular CLI v22.0.7

## Validation Scenarios

### 1. Task Creation & Viewing
1. Start the application: `ng serve`
2. Navigate to `http://localhost:4200/`
3. Click "New Task"
4. Fill in task details and click Save
5. Verify the task appears in the main task list

### 2. Task Editing
1. Click on an existing task in the list
2. Modify task fields and click Save
3. Verify task details are updated in the list

### 3. Task Filtering
1. Click into the search box and type some letters and see the task that most closely resembles those letters appear first.

### 4. Task Sorting
1. Click on any column header up or down arrow and see the tasks sort.

### 5. Pagination
1. Click on the pagination bar to show 5, 10 or 25 tasks per page depending on what number was selected.
